== NEW FEATURES ==

1. ROUND COUNT SELECTOR (Setup Screen)
   - New "Number of Rounds" section added to setup, below the timer presets
   - Options: ∞ Free Play (default) | 3 Rounds | 5 Rounds | 7 Rounds
   - Active selection highlighted in yellow
   - "Free Play" = unlimited rounds (original behaviour)
   - For team mode: each team plays N rounds; total turns = N × team count
   - For classic mode: player plays N turns total

2. CUMULATIVE SCORE TRACKING
   - Team scores accumulate across ALL rounds within a game session
   - Scores reset only when starting a brand new game (New Game → setup → start)
   - Score screen already showed "total pts" — now this is truly tracked per round

3. ROUND PROGRESS INDICATOR (Score Screen)
   - When a round limit is set, score screen shows "ROUND X OF Y" above cards
   - Hidden when in Free Play mode

4. GAME OVER / WINNER SCREEN
   - After all rounds are complete, score screen transforms:
     - Title changes to "Game Over!"
     - Emoji changes to 🏆
     - Gold "Game Over!" banner appears with winner announcement
     - Team mode: "🎉 [Team] wins with X points!"
     - Classic mode: "🎯 Total score: X points!"
   - "Play Again" button replaced by "🔄 New Game" → returns to setup
   - Normal "Change Deck", "Leaderboard", "Home" buttons remain

5. CUSTOM TEAM NAME PERSISTENCE
   - Team names entered in Team Setup are saved to G.teams[i].name before game starts
   - Names persist across all rounds until a new game is started
   - Names appear in: ready screen, score card, winner announcement

== TECHNICAL CHANGES ==

G object additions:
  maxRounds: 0         // 0 = unlimited; set by round selector
  gameTurnCount: 0     // total turns played since startGame()
  classicTotal: 0      // cumulative score for classic (solo) mode

New functions:
  setMaxRounds(n)      // sets maxRounds, updates active preset button
  isGameOver()         // true when gameTurnCount >= maxRounds × teamCount

Modified functions:
  endRound()           // increments gameTurnCount; increments classicTotal for classic mode
  showScore()          // shows round info + game-over state when applicable
  startGame()          // resets gameTurnCount and classicTotal on new game
  proceedSetup()       // resets gameTurnCount and classicTotal for classic mode

CSS additions:
  .tpreset.rp-active   // active state for round preset buttons (same yellow style as :active)

Score screen HTML additions:
  #sc-title            // now has id so JS can change "Round Over!" → "Game Over!"
  #sc-round-info       // "ROUND X OF Y" indicator (hidden when Free Play)
  #sc-gameover-banner  // gold winner banner (hidden normally)
  #sc-winner-text      // winner name + score inside banner
  #sc-play-again-btn   // id added so JS can swap text/onclick for game-over
