1. App Overview & Game Modes

WhamBam! is a party game app featuring the TOP 3 party games in 1 app. It includes 24 decks, tilt controls, voice commands, and team play.

The 3 Game Modes

ModeHow It WorksOrientationControls
🙆 Up Top!! Phone on forehead — others see the word and give verbal clues. Player guesses. Landscape Tilt forward = Correct, Tilt backward = Skip. Voice commands optional.
🤫 Charades!! Only you see the word — act it out without speaking. Others guess. Portrait (default) or Landscape Manual buttons only. Tilt & voice toggles are disabled.
🚫 Don't Say It!! Hold phone facing you — describe the word to your team without saying the forbidden words shown on screen. Portrait Manual buttons only. Tilt & voice toggles are disabled.

Play Modes

  • 🎯 Classic — single player / pass-and-play
  • 👥 Team — 2–6 teams take turns, highest score wins

Timer Options

30s, 45s, 60s (default), 90s, 2 min, 3 min

Round Options

∞ Free Play (default), 3 Rounds, 5 Rounds, 7 Rounds

2. Test Environment Setup

iOS (TestFlight) iOS

  • Install TestFlight from the App Store
  • Accept the invite link sent to your Apple ID email
  • Install WhamBam from TestFlight
  • Ensure device is on iOS 16 or later
  • Ensure device is NOT in Low Power Mode (affects sensors)

Android Android

  • Install APK directly (or accept Play Store internal test invite)
  • Enable "Install from unknown sources" if using APK
  • Ensure device is on Android 8.0 (API 26) or later
  • Grant all permissions when prompted
Debug Mode: Tap the top-right corner of the Home screen 6 times rapidly. This enables a live sensor overlay showing x/y/z values, roll, gamma, and armed state. Use this to diagnose tilt issues.

3. Up Top!! Mode Testing

iOS & Android   Priority: HIGH

Phone on forehead — others see the word and give verbal clues.

  • Select "Up Top!!" from mode selection screen
  • Choose a deck — deck grid shows with word count labels
  • Tilt and Voice toggles are ENABLED (full opacity, interactive)
  • Game prompts landscape orientation before starting
  • Word card appears with category label (green pill) above it
  • Word text displays in UPPERCASE
  • Tilt forward (away from face) → registers CORRECT (green flash + sound)
  • Tilt backward (toward face) → registers SKIP (red flash + sound)
  • Next word appears immediately after correct/skip
  • Timer counts down visibly during gameplay
  • Round ends when timer hits zero
  • Score screen displays in PORTRAIT with correct/skipped tallies
  • Word list on score screen shows each word with correct/skip status
  • "Play Again" button starts a new round with same settings
  • "Home" button returns to main menu
  • Words do NOT repeat within the same round

Voice Commands (Up Top!! only)

  • Enable Voice toggle on setup screen
  • Microphone permission prompt appears (first time)
  • Listening pill/indicator appears during gameplay
  • Say "Correct" or "Yes" → registers as CORRECT
  • Say "Skip" or "Next" → registers as SKIP
  • Voice commands work alongside tilt (both active simultaneously)
  • Chrome-only warning appears on unsupported browsers

4. Charades!! Mode Testing

iOS & Android   Priority: HIGH

Only you see the word — act it out, no talking!

  • Select "Charades!!" from mode selection screen
  • Choose a deck — deck grid shows normally
  • Tilt toggle is GREYED OUT (opacity 0.35, not clickable, unchecked)
  • Voice toggle is GREYED OUT (opacity 0.35, not clickable, unchecked)
  • In portrait (default): card displays vertically — large text facing you/audience
  • In landscape: card displays in standard landscape layout (same as Up Top)
  • Manual CORRECT button works
  • Manual SKIP button works
  • No landscape prompt — game starts directly (portrait is default)
  • Timer runs and round ends correctly
  • Score screen works same as Up Top mode

5. Don't Say It!! Mode Testing

iOS & Android   Priority: HIGH

Hold phone facing you — describe the word to your team without saying the forbidden words!

  • Select "Don't Say It!!" from mode selection screen
  • Deck selection is HIDDEN — this mode uses its own fixed mega-deck
  • Tilt toggle is GREYED OUT (not clickable)
  • Voice toggle is GREYED OUT (not clickable)
  • Game plays in PORTRAIT orientation
  • Word card shows the TARGET word prominently
  • FORBIDDEN words list displays below the target word (with ✕ markers)
  • Category hint is HIDDEN in this mode
  • Manual CORRECT button works (described successfully without forbidden words)
  • Manual SKIP button works (marked with "buzzer" button)
  • "Change Deck" button is HIDDEN during this mode
  • Timer runs and round ends correctly
  • Score screen works same as other modes
  • Font size for target word is slightly larger than other modes

6. Tilt & Sensor Testing

iOS & Android   Priority: HIGH   (Up Top!! mode only)

  • Tilt responds within ~250ms of completing the gesture (sustained hold required — intentional)
  • No accidental triggers while phone is held still at forehead
  • Both tilt directions (forward/backward) work reliably
  • Rapid consecutive tilts have a brief cooldown (~300ms, no double-fires)
  • After a tilt registers, phone must return to neutral before next tilt works
  • Tilt works in BOTH landscape orientations (phone can be held either way)
  • Tilt does NOT fire when phone is held portrait/vertical
  • Tilt does NOT fire during countdown screen
  • Tilt does NOT fire after round ends
  • Tilt does NOT fire in Charades or Don't Say It modes (toggles disabled)
Known & accepted behavior: A slight asymmetry between forward/backward sensitivity is normal — one direction may feel marginally easier depending on hand angle. An off-centre resting hold can make one direction nearer its threshold. This is NOT a bug.

Platform-Specific Tilt Notes

PlatformBehavior
iOSMotion permission dialog appears on first use. If denied, tilt won't work — user must re-enable in Settings > WhamBam > Motion & Fitness. Additionally, screen.orientation.lock() is NOT supported on iOS — app uses physical gyroscope check instead.
AndroidNo runtime permission needed for accelerometer. Orientation lock works natively. Tilt should work immediately.

7. Game Setup Flow

iOS & Android   Priority: HIGH

  • Home screen loads with WhamBam branding and play button
  • Mode selection shows all 3 games as comic-style panels (Up Top / Charades / Don't Say It)
  • Tapping a mode panel navigates to setup screen with correct banner color and label
  • Setup screen banner shows mode name with correct tint (green/pink-purple/blue)
  • Tapping setup banner returns to mode selection
  • Deck selection shows grid with word count labels (hidden for Don't Say It)
  • Play mode selector: Classic (default) / Team
  • Selecting Team mode reveals team count (2–6) and team setup
  • Timer presets: 30s, 45s, 60s (default), 90s, 2 min, 3 min
  • Round presets: ∞ Free Play (default), 3, 5, 7 rounds
  • Team setup screen: add/remove teams, edit names, add players (optional)
  • Ready screen shows team name and "▶ START!" button
  • Tapping START triggers countdown: 3… 2… 1… LET'S GO!!! (yellow final frame)
  • "← Go back" pill buttons navigate backward through flow correctly
  • How-to guide appears on first play of each mode (dismissible)

8. Device Permissions

iOS iOS

  • Motion & Orientation permission dialog appears before first Up Top!! game
  • Accepting permission → tilt works immediately
  • Denying permission → game still playable via manual buttons
  • After denying: re-granting in iOS Settings restores tilt on next launch
  • Microphone permission requested only if Voice toggle is enabled (Up Top!! mode)
  • Denying microphone → voice won't work but tilt and buttons still function

Android Android

  • No special permission needed for accelerometer/gyroscope
  • Microphone permission requested only if Voice toggle is enabled
  • App works correctly if microphone permission is denied (voice just won't work)

9. Orientation & Layout

iOS & Android   Priority: HIGH

  • Home / Mode Select / Setup / Teams / Score screens display in PORTRAIT
  • Up Top!! gameplay operates in LANDSCAPE
  • Charades gameplay defaults to PORTRAIT (can also work in landscape)
  • Don't Say It!! gameplay operates in PORTRAIT
  • Up Top!! shows landscape prompt before game starts ("rotate your phone")
  • Score screen shows "rotate to portrait" overlay if held in landscape
  • No content gets cut off by notch / Dynamic Island / camera punch-hole
  • Safe area insets respected on all screens
  • Fullscreen button hidden during gameplay and countdown
  • Layout doesn't glitch when rapidly rotating the device

Platform-Specific

PlatformNote
iOSOrientation lock is NOT supported in WKWebView. App relies on physical device orientation detection. Verify landscape is detected properly in Up Top mode.
AndroidOrientation lock works natively. Verify screens lock to correct orientation per mode.

10. Audio & SFX

iOS & Android   Priority: MEDIUM

  • CORRECT sound plays on successful tilt/tap (all modes)
  • SKIP sound plays on skip tilt/tap (all modes)
  • Tap/UI sound plays on button presses throughout the app
  • Countdown beeps play for 3-2-1
  • Round-end buzzer plays when timer expires
  • Voice command acknowledgement beep plays (Up Top!! with voice enabled)
  • No audio delay or stutter during rapid tilts/taps
  • Audio does NOT play when app is backgrounded
  • Audio respects device silent/mute switch (iOS) / Do Not Disturb (Android)
  • Audio works with Bluetooth headphones connected
  • Volume is appropriate (not too loud on max, audible on mid)

11. Authentication & Access

iOS & Android   Priority: MEDIUM

  • Sign-up tab: password under 8 characters → shows error, blocks submission
  • Sign-up tab: "Forgot password" link is NOT visible
  • Sign-in tab: "Forgot password" link IS visible and functional
  • Sign-up with valid email + password (8+ chars) → account created
  • Sign-in with valid credentials → success, returns to app
  • Sign-in with wrong password → clear error message
  • Sign-out → returns to logged-out state
  • Tab switching (Sign In / Sign Up) is smooth, no UI glitches
  • Free decks accessible without any login
  • Premium/locked decks show lock indicator
  • Purchasing/unlocking a deck → deck becomes playable immediately
  • Access persists after closing and reopening the app

12. Achievements & Progress

iOS & Android   Priority: LOW

  • Complete a round with 5+ correct and 0 skips → "Perfect Round" achievement toast appears
  • Achievement persists after closing and reopening the app
  • Achievement does NOT re-trigger on subsequent perfect rounds (already unlocked)
  • Game history / resume: closing app mid-game and returning shows resume prompt

13. Edge Cases & Stability

iOS & Android   Priority: HIGH

  • Background the app mid-game → return: app resumes or resets cleanly (no crash)
  • Receive a phone call during gameplay → return: app recovers
  • Notification banner during gameplay → does not interfere with tilt/buttons
  • Lock screen during game → unlock: app still functional
  • Play 5+ consecutive rounds → no slowdown, memory leaks, or crashes
  • Rapidly tap buttons during countdown → no broken state
  • Kill app and reopen → returns to Home screen cleanly
  • No internet connection → app still functional (offline-first game)
  • Low battery / Low Power Mode → tilt still works (especially iOS)
  • Switch between all 3 game modes in rapid succession → no stuck state
  • Play all 3 modes in one session without restarting → no cross-mode bugs
  • Team mode: complete full multi-round game with 3+ teams → leaderboard correct
