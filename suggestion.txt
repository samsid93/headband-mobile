WHAM BAM — WEB GAME AUDIT SUGGESTIONS
Date: 2026-07-04
Source: Full codebase audit of headband-game-web.html
=======================================================


SECTION 1 — CODE HEALTH (BUGS & RISKS)
=======================================================

[HIGH] 1.1 Old navy palette remnants (~10 places)
  Game was rebranded to warm black (#0A0500) but these still use
  the old blue-purple theme:
  - Canvas background fills #06060E (cool blue-black) every frame (line ~1081)
  - .sbubble background rgba(14,10,44,.9)
  - .tpill background rgba(22,18,64,.9)
  - #play-back-btn background rgba(7,5,26,.85)
  - .demo-phone background rgba(30,24,72,0.95)
  - Timer ring track (.tbg) stroke rgba(30,24,82,.9)
  - .unlock-card background rgba(14,10,44,.97)
  - .fp-modal-wrap background rgba(14,10,44,.98)
  - Auth modal backdrop rgba(7,5,26,0.92)
  - How-to modal backdrop rgba(6,6,14,.92)
  Fix: replace with warm equivalents (rgba(26,12,0,...) family).

[HIGH] 1.2 beepNewWord() creates a NEW AudioContext on every word (line ~2024)
  iOS caps ~4 AudioContexts per page — after several words audio
  silently dies. Fix: reuse the SFX module's shared context.

[MEDIUM] 1.3 XSS in player names
  renderPlayers() injects names via innerHTML unescaped.
  A name like <img src=x onerror=alert(1)> executes.
  Local-only today, becomes real risk once names sync to Supabase /
  global leaderboard. Fix: escape before injecting.

[MEDIUM] 1.4 Canvas + floaties never sleep
  Orb animation (requestAnimationFrame + ~40 grid strokes per frame)
  and floaty spawner (every 1.8s) run during gameplay, countdown,
  everything. Battery drain on phones.
  Fix: pause both when not on home/setup screens.

[LOW] 1.5 Supabase SDK script tag in <head> has no defer — blocks first paint.

[LOW] 1.6 clearLB() uses native confirm() dialog — inconsistent with
  styled modals used everywhere else.

[LOW] 1.7 No OG/meta description tags — link shares on WhatsApp/social
  show nothing. Party game spreads via link sharing; matters for growth.

[LOW] 1.8 File weight ~400KB+ (11 decks x 600 words inline).
  Slow first load on mobile data. Fine for now; revisit when backend
  serves decks (Phase 0).


SECTION 2 — GUI OBSERVATIONS
=======================================================

STRONG POINTS:
  - Vivid per-deck card colors
  - Gradient headings, glow system
  - LET'S GO countdown frame
  - Tilt tutorial with animated phone demos

GAPS:
  2.1 No mute button anywhere. SFX always plays. Needs settings toggle
      on home or setup, persisted in localStorage.
  2.2 Word card is always yellow regardless of deck. Deck color identity
      vanishes during play.
  2.3 Score numbers appear instantly — no count-up animation.
  2.4 Team turn hand-off is just a thin text bar. Passing the phone is
      THE core social moment — deserves a full-screen splash with
      team color ("Pass to Team 2!").
  2.5 Countdown 3-2-1 uses the same gradient for all numbers — no color
      escalation / urgency build.

SECTION 4 — COLOR SUGGESTIONS
=======================================================

  4.1 Deck-tinted gameplay — word card border + category pill inherit
      the deck's color (Movies red, Animals green, Sports blue...).
      Play screen stops being monotone yellow; every deck feels distinct.
  4.2 Countdown color ramp — 3 = yellow, 2 = orange, 1 = red-pink,
      LET'S GO = full yellow flash (keep). Urgency through color.
  4.3 Team-colored rounds — during team play, timer ring + team bar +
      correct-flash use that team's color.
  4.4 Score podium colors — winner card gold glow, 2nd silver, 3rd bronze
      (rank classes already exist for leaderboard, unused on score screen).
  4.5 Streak color ladder — combo banner shifts yellow → orange → red →
      purple as streak grows.
  4.6 Fix navy remnants first (Section 1.1) — right now "extra color"
      reads as inconsistency, not vibrancy.
